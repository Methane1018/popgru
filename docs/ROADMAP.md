# POPGRU 開發計畫

> 目標：v1.0。每個階段都能單獨上線，不會做到一半卡住。

## 已定案的設計原則

這些是討論後拍板的，後面所有功能都要符合：

| 原則 | 為什麼 |
|---|---|
| **壓扁沒有中間幀** | 瞬間硬切是這遊戲的核心笑點。任何動畫都不能加在「一般點擊」上 |
| **裝扮看「持有」不看「配備」** | 不然會有人被迫戴醜帽子只因為它比較強 |
| **增益的份量和趣味分開** | 裝扮給微量（每件 0.5%，上限 30%）；有個性的效果留給寶物 |
| **不做互相偷竊** | 對等的偷竊沒有勝負，只有沒完沒了的報復。改成搶「大家都還沒拿到的」 |
| **干擾必須限時、可見、無永久損失** | 純丟臉可以，永久損失不行 |
| **連續天數不能被刷** | 那是唯一防得住的指標，自動點擊不能算進去 |
| **美術走拼貼** | 格魯維持照片，其他圖層可以是任何風格。中間地帶（半寫實）最糟 |
| **深度來自後期解鎖** | v0.9 之後的檢討：前面每一版都是同一個迴圈換皮，那是廣度。<br>樹上永遠要有你看得到、但現在還學不起的節點 |
| **不做洗點** | 選擇有重量才有意義。點不滿整棵樹是故意的 |

## v0.9　圖鑑（已完成）

24 個寶物：掉落 8、成就 10、彩蛋 4、商店 2。

**增益刻意分散在 7 條軸上**（魚產出／幫忙額度／掉落機率／金魚門檻／雙倍卡長度／
凍結卡折扣／道具折扣），不是每個都「魚 +X%」——那樣收集 20 個只是一個數字變大，
記不住哪個是哪個，也容易疊爆。

四個彩蛋：整點壓一下、連戳格魯的腳 10 下、連點版本號 5 下、一口氣壓 100 下不停超過 2 秒。
**圖鑑對未解鎖的給提示但不給增益** —— 有方向，仍然要自己動手。

資料庫成本：只多存 `treasures`（id 陣列）、`helped`（幫過誰）、`giftsReceived`。
圖鑑面板不需要任何新查詢，資料就在既有的個人文件裡。安全規則不用改。

## v0.10　技能樹（已完成）

設計細節見 [SKILLTREE.md](SKILLTREE.md)。

三軸各四層、共 33 點，而技能點最多只拿得到 24 點 —— **點不滿是故意的**。
探寶軸第 3、4 層是「權限」而不是數值：沒點出來，傳說與神話寶物永遠不會掉。
那是這個版本想證明的東西 —— 深度不是加更多收集品，是讓你知道有東西還拿不到。

技能點總數完全由 `lifetime` 推導，資料庫只多存一個 `skills` 陣列（arrayUnion）。
**算得出來的就不要儲存**：沒有計數器，就沒有被快照覆蓋而回滾的機會。
安全規則不用改（`users` 是整份 `isMe`）。

## 需要美術的地方

格魯是照片，所以其他圖層要嘛明顯是貼紙（現在的 emoji），要嘛整體轉全插畫。**半寫實會卡在恐怖谷。**

規格（如果要自己畫）：

- 去背 PNG
- 基準尺：**兩眼間距 = 畫布寬的 18.4%**。手持物畫成 1～1.5 個眼距寬最自然
- 要指定圖上哪一點對齊錨點（例如槍托、握把）
- **液壓機要兩張：壓下前／壓下後**，才能維持硬切的調性

錨點（對齊後畫布 1629×1302，換姿勢會自動跟著移動）：

| 位置 | 站姿 | 壓扁 |
|---|---|---|
| 頭頂（帽子） | 50.4%, 1.6% | 50.4%, 28.9% |
| 右翅尖（手持物） | 98.7%, 50.3% | 95.2%, 57.0% |
| 左翅尖 | 3.3%, 55.3% | 1.3%, 61.6% |
